自定义字体

先在 source\fonts 里保存字体, 然后在 %THEME%\source\css\font.styl (or style.styl) 里加上 @font-face 的声明.

然后使用 [自定义字体文本]{style="font-family: 'MyFont'"} 即可.

Sources 插入

Video

  • <iframe>: 网络资源
  • <video>: 本地资源
  • hexo-tag-dplayer 插件: {% dplayer “url=…” “pic=…” “loop=…” “theme=…” “autoplay=…” %}

Audio

  • <audio>
  • hexo-tag-aplayer 插件: 更好看的界面, {% aplayer “歌曲名” “作者” “/audio/song.mp3” “/images/music/song-cover.jpg” %}

PDF

  • <ifram>
  • {% pdf xxx.pdf %}

双向链接

用法仿照 Obsidian, 如下:

  • [[title]]: 指向链接的文章, 可以是不存在的文章.
  • [[title | name]]: 允许使用别名, 显示的文字会变为 name.
  • 可以通过元数据 backlinks 设置是否显示反向链接.
  • 出于测试目的, 我们链接一下 TEST POST.

Post 元数据

  • breaks: true/false: 默认为 true, 控制文章的书写模式.
  • featured_image: url/[url, text, link]: url: 头图链接; text: 显示在图片正下方的文本, 一般放作者信息; link: 存在时 text 变为超链接; 默认为一条分割线.
  • title_style: "css-style": 设置标题显示的字体.
  • list_title_style: "css-style": 设置标题在列表里显示的字体.
  • backlinks: true/false: 默认为 false, 控制是否显示反向链接.
