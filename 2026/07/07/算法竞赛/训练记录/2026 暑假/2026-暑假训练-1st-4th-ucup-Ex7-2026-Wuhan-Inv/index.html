B. Sequence Operations

题意:

赛时: 简单题, 没什么好说的, 但写的时候没带脑子, 犯了各种错, 比如算 gcd 时直接修改了原数组之类的.

题解: 首先一个简单的转换是只要某个时刻两个数相同, 则无论如何操作结束时一定仍然相同, 所以只要在某个时刻让所有数相同即可.

注意到给的 xix_{i}xi​ 一定大于 000 (刚开始没看到想了好久), 于是不存在 000 时, mex 操作一定能让所有数全部变成 000, 又 gcd 操作一定能让所有数不为 000, 所以只要操作序列中有形如 gcd ... mex 的子段, 就一定合法.

判完上面的情况后, 剩下的情况只有两种:

  1. 所有操作均为 gcd: 显然把所有 xix_{i}xi​ 取 gcd 后模拟一下操作结果就行.
  2. 操作序列形如 mex ... mex (?) gcd ... gcd, 其中 (?) 表示可能有 ? 也可能没有: 因为 ??? 最多只有一个, 于是暴力考虑两种情况就好, 对于前面的 mex, 执行一次后剩下的不同数的个数不超过 333, 可以直接暴力模拟, gcd 同情况 1.

D. Prime Game

题意:

赛时: 简单题, 队友刚开始想简单了, 按照队友思路改了下后让他去写了, 同样罚时爆炸.

题解: 显然 Iroha 操作完后游戏一定不会结束, 于是不妨考虑完整一轮带来的影响.

令当前的数为 xxx, 一轮结束后数为 yyy, 一个直觉就是我们希望 α=xy\alpha = \frac{x}{y}α=yx​ 尽量小.

注意到一个关键性质是: Iroha 总可以通过操作 xxx 使其变为 222 的幂, 于是 α\alphaα 总可以小于等于 222.

又因为 Iroha 无论如何操作, xxx 放大倍数不会超过 222, 因此只要 Kaguya 能除去一个大于等于 444 的素数时, α\alphaα 总是大于 222, 即更劣的.

于是只用考虑仅包含素因子 2,32, 32,3 的情况, 预处理出范围内所有满足条件的数后, DP 一下就行了.

严谨证明比较复杂, 感性理解一下吧.

F. Lottery

题意:

赛时: 一眼弱智题, 然后遇到了更弱智的我. 大概 100 min 时看的题, 然后想了一下, 感觉倒着模拟一定轮数基本就对了, 结果从 120 min 第一次交到 260 min 才过, 原因是一个 while 写成 if 了的超唐错误, 毁了我整场体验的题目.

题解: 令 FNF_{N}FN​ 表示第 NNN 轮开始的最优期望, wNw_{N}wN​ 表示第 NNN 轮的花费. 容易得到下面这个式子:

FN+1=1n∑i:Ai≥wNAi+1n∑i:Ai<wNFNF_{N + 1} = \frac{1}{n} \sum_{i : A_{i} \geq w_{N}} A_{i} + \frac{1}{n} \sum_{i : A_{i} < w_{N}} F_{N} FN+1​=n1​i:Ai​≥wN​∑​Ai​+n1​i:Ai​<wN​∑​FN​

对于 k=0k = 0k=0, 即 wNw_{N}wN​ 不变的情况下, 显然答案是一个简单的级数求和.

对于 k>0k > 0k>0, 不妨考虑 NNN 足够大的情况, 显然一定有 FN=∑AiF_{N} = \sum A_{i}FN​=∑Ai​. 于是用双指针倒推即可 (也就是双指针我写成 if 了, 唉唉).

另外, 因为这道题要求是满足误差即可, 所以其实对于 k=0k = 0k=0 的情况, 我们也直接递推就行, 具体误差没有分析, 但能过 ().
